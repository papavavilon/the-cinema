# Вимоги екзамену та стан The Cinema

Перевірка станом на 27 листопада 2026 року.

| Вимога | Реалізація та стан |
|---|---|
| PHP як основна платформа | Обробка сторінок, форм, авторизації й бронювання працює в PHP |
| Щонайменше 3 використані класи | Database, MoviesController, MoviesModel, CheckoutAction, CheckoutModel та інші |
| Design pattern | Структура MVC описана в README та реалізована папками моделей, контролерів і шаблонів |
| Каталог фільмів із бази | MoviesController та MoviesModel, пошук за назвою, колекцією й датою |
| Повний список залів із бази | AboutModel::halls та шаблон about/halls.php |
| Новини | NewsController і NewsModel |
| Головна з новинами | HomeModel::fetchNews та шаблон головної |
| Головна із сьогоднішніми сеансами | HomeModel::today та шаблон home/today.php |
| Опис компанії на головній із бази | HomeModel::company |
| Профіль | ProfileController, редагування email і телефону, перегляд замовлень |
| Checkout | CheckoutAction, серверний розрахунок суми, промокоди, рахунок |
| Вибір і бронювання місць | SeatController, SelectSeatsAction, перевірка від 1 до 5 місць у PHP |
| Захист від подвійного бронювання | Транзакція, блокування сеансу й унікальний індекс у Ticket |
| Справжня оплата | Окремий необов’язковий етап. Поточне оформлення демонстраційне |
| Контактна форма з поштою | Збереження перевірено. SMTP-код готовий, налаштування відкладено власником |
| Захищена сесією адмінпанель | Вхід, хешування пароля, перевірка admin_id та CSRF |
| Огляд бронювань | Адмінпанель показує замовлення, рахунки та скасування |
| Invoice creator | StaffInvoiceAction створює рахунок або відкриває наявний без дублювання |
| Зміна опису, годин роботи й контактів | Розділ Cinema details |
| CRUD фільмів і сеансів | Розділи Films та Screenings |
| Фільми на головній | Розділ Spotlight films, денні сеанси беруться з розкладу |
| CRUD новин | Розділ Journal |
| DB script | database/schema.sql, перевірено імпорт у тестову базу |
| Views | detailedbookings і moviedetails, визначення та пояснення в SQL-скрипті |
| Triggers | check_screening_overlap та check_screening_overlap_update, обидва перевірено |
| Separation of concerns | SQL у моделях, обробка запитів у контролерах, HTML у шаблонах, CSS і JS окремо |
| Українські пояснення | Коментарі до файлів, методів та основних блоків власного коду |
| Рядки до 150 символів | Перевірено власні PHP, CSS, JS та SQL. Код сторонньої PHPMailer збережено як бібліотеку |
| Live server | Опубліковано на https://thecinema.fwh.is/; доступність треба повторно перевірити |
| DB-діаграма | Підготовлено outputs/exam/Database-diagram.pdf у робочій папці Codex |
| Sitemap, flowchart і звіт до 10 сторінок | Підготовлено outputs/exam/DWP-report.pdf (5 сторінок) у робочій папці Codex |

Реєстрацію, вхід, профіль, контактну форму, бронювання, рахунки, скасування та CRUD перевірено на окремій тестовій базі.
Робоча `thecinema_v2` використовується для сайту в XAMPP.

Публічний хостинг InfinityFree не дозволяє створювати views/triggers; повний SQL-скрипт демонструється локально.
Реальна оплата та SMTP потребують окремого налаштування.
